# Data-Mining
Este repositorio reúne proyectos académicos de minería de datos, realizados aplicando distintas técnicas de análisis exploratorio, reducción de dimensionalidad (PCA, Isomap, t-SNE) , (clustering K-Means y clustering jerárquico), regresión (Árboles), clasificación (Naive Bayes, k-NN, Árboles de Decisión)y evaluación de modelos.
